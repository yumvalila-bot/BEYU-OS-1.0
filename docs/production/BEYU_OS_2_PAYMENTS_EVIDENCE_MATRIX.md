## Reading rules for anyone citing this matrix

1. Cite the artifact, not the claim. Every row above names a file or a command; a claim whose
   artifact was a previous report was treated as unverified and re-measured (defects 1–9 in
   `PAYMENT_TEST_EVIDENCE.md` are what that re-measurement produced).
2. "VERIFIED LOCALLY ONLY" is a status, not a step toward "verified".
3. Nothing in this matrix changes a gate in `docs/production/BEYU_OS_2_PRODUCTION_READINESS*.md`.
   Payment work shipped inside the payment domain; the platform's blockers stand.
