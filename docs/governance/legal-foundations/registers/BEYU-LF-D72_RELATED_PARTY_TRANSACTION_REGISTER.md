> **⚠ THE SINGLE TEST.**
> **Would the group have done this, on these terms, with an unrelated party?**
> If the answer is **no**, the transaction is either **not permitted**, or it needs a **documented reason** and
> the **highest** approval (and, for the Foundation, the independent process).
> **And the register's second rule: A TRANSACTION ENTERED AFTER THE EVENT IS A FINDING, NOT A RECORD.**
> The register is populated **at proposal**, not at completion — because its purpose is to make the analysis
> happen, not to describe it afterwards.

## 1. Who is a "related party" (the wide test)

| # | Category |
|---|---|
| 1 | A **director, trustee, officer, protector** or a member of the Foundation's governing body |
| 2 | A **family member** — under the definition adopted (and **currently unresolved: `FIR-003`** — the family must adopt one before this test can be applied reliably) |
| 3 | An entity **controlled** by any of the above, or in which they hold a material interest |
| 4 | A **trust** of which any of the above is trustee or beneficiary |
| 5 | Another **group entity** (intra-group transactions are included — see §3) |
| 6 | The **Foundation** and the **Family Office** |
| 7 | A **close associate** — a person with whom any of the above has a personal or business relationship that a third party might think influenced the transaction |
| 8 | A **person who was** in any of the above categories within `[N]` months |

**1.1 The perception test.** If a **journalist, a regulator, a donor or a minority shareholder** would ask
"why is the family's company dealing with the family's other company on those terms?", the transaction is
a related-party transaction — **whatever the technical analysis says.**

## 4. Controls

| # | Control |
|---|---|
| C-01 | **Entry at proposal**; the entry is created even if the transaction is later abandoned (with the reason) |
| C-02 | **Disinterested decision mandatory** (`D27` N-4: non-delegable) |
| C-03 | **The arm's-length comparison is produced before the decision** — never after |
| C-04 | **No self-approval**; no approval by an entity the interested person controls |
| C-05 | **For the Foundation: `D51` applies in full**, with the independent quorum and the refusal power |
| C-06 | **Quarterly review** by the Audit and Risk Committee for completeness ( **"no entries" is itself a finding** if transactions are known to have occurred) |
| C-07 | **Continuing arrangements are re-tested annually** and terminated when they no longer pass |
| C-08 | **The register is reconciled** with the accounting records — an undisclosed related-party payment is a
control failure, not an oversight |
| C-09 | Access is restricted; the register contains personal data and commercially sensitive terms |
| C-10 | **No bulk import of seeded or fixture data** (`GATE-0` §6) |
